# Arvind & Maile wedding invitation

The page styles and three cropped deity images are embedded in `index.html`. The music is in the accompanying `malai-matrinal.mp3` file.

Upload both `index.html` and `malai-matrinal.mp3` to the root of your GitHub repository. In Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`, and save. Share the published URL.

The page loads an optional Google Font; its fallback fonts work without it. The reception address is absent from the supplied invitation and therefore is not listed.

Music loops and is attempted two seconds after the page loads. Most mobile browsers block automatic sound until a visitor interacts with the page. The visible music button lets them start or pause playback. Keep the MP3 beside `index.html` or the audio will not load.
