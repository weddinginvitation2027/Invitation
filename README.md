# Arvind & Maile wedding invitation

This invitation is a single, self-contained HTML file. The three cropped deity images and page styles are embedded in `index.html`, so no asset folder is required.

Upload `index.html` to the root of your GitHub repository. In Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`, and save. Share the published URL.

The page loads an optional Google Font; its fallback fonts work without it. The reception address is absent from the supplied invitation and therefore is not listed.
